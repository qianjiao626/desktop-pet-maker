# 让豆包生成桌宠素材 — 完整操作文档

> 这份文档给你自己看。里面**第二节那段是可以整段复制发给豆包的**。
> 路径、要求、自检方式都写好了，照做即可。

---

## 一、素材放哪里（路径已建好）

| 用途 | 路径 |
|---|---|
| **豆包生成的图放这里** | `D:\桌面文件\桌宠制作器\素材\原始素材\` |
| 自检合格后的素材 | `D:\桌面文件\桌宠制作器\素材\已通过自检\` |

两个文件夹**我已经建好了**，直接把图丢进「原始素材」就行。

> 提醒豆包：要**真的把文件保存到这个文件夹**，不能只在对话里显示图片。
> 如果豆包存不了文件，就让它把图发给你，你自己拖进「原始素材」。

## 二、复制这段发给豆包（整段复制）

```
请帮我生成一批 2D 游戏角色素材，用于桌面宠物制作器。
请严格按下面的要求生成，并把我生成的图片全部保存到这个文件夹：
D:\桌面文件\桌宠制作器\素材\原始素材\

【每个角色都必须满足 —— 这些是硬性要求，不是风格偏好】
1. 全身立绘：从头顶到脚底完整入画，四周留出空白，手脚不能被画面裁掉
2. 正面朝向镜头，身体站直，不要侧身、不要回头、不要倾斜
3. 双臂向斜下方张开约 45 度（腋下要能看到空隙，手臂不能贴着身体）
4. 双腿微微分开（两腿之间要能看到空隙，不能并拢、不能交叉）
5. 双手张开、不拿任何东西（不能插兜、不能抱胸、不能背手）
6. 接近真人的身体比例，约 7 到 7.5 头身（不要大头娃娃、不要 Q 版）
7. 柔和的赛璐璐上色，有明确的光影和体积感（不要纯色色块）
8. 干净的纯浅灰背景（#E8E8E8 左右），没有任何道具、场景、地面阴影
9. 光线均匀，边缘清晰，分辨率 1024x1024 或更高

【反向要求 —— 绝对不要出现】
chibi、超变形、大头小身子、夸张大眼睛、手臂交叉、手插口袋、
手背在身后、拿着任何物品、双腿并拢、双腿交叉、肢体互相遮挡、
手脚被裁切、侧视、四分之三侧视、背面、身体倾斜、坐姿、跳跃、
杂乱背景、场景元素、地面投影、动态模糊、低分辨率

【请生成的 6 个角色（每个独立生成一张图）】
1. 一个圆润可爱的女孩，浅蓝色短袖和白色短裤，短发
2. 一个圆润可爱的男孩，橙色卫衣和深灰长裤，短发
3. 一只拟人化的小猫，橘色，穿浅绿色上衣
4. 一只拟人化的小狗，米白色，穿蓝色背带裤
5. 一只拟人化的小兔子，淡粉色，穿浅黄色连衣裙
6. 一只拟人化的小恐龙，浅绿色，穿橙色背心

【风格统一要求】
6 个角色必须用同一套画风、同一套光影、同一个背景色，像同一个系列。

【输出要求】
- 每张图单独一个文件，不要拼图、不要九宫格
- 文件名用：角色1_女孩.png、角色2_男孩.png、角色3_猫.png、
  角色4_狗.png、角色5_兔.png、角色6_恐龙.png
- 全部保存到 D:\桌面文件\桌宠制作器\素材\原始素材\
- 全部生成完后，把该文件夹里的文件列表列给我确认
```

## 三、为什么要求长这样（实测数据）

桌宠制作器识别身体用的是 **MoveNet** —— 它在**真人照片**上训练。
我在本机实测了 4 种画法，数字是真跑出来的：

| 画法 | 识别到的关键点 | 结果 |
|---|---|---|
| **写实比例 + 有光影 + 四肢张开** | **16 / 17** | ✅ 合格 |
| 写实比例 + 纯色无明暗 | 13 / 17 | ⚠️ 勉强 |
| 写实比例但**四肢并拢** | **8 / 17** | ❌ 被拒 |
| 扁平矢量小人（大头 Q 版） | 9 / 17 | ❌ 被拒（躯干都认不出） |

**两条最要紧的**：

1. **别画大头 Q 版** —— 要接近真人比例（约 7 头身）
2. **四肢必须张开** —— 这条比「画得精细」影响大得多（16 分 vs 8 分）

第 2 条有点反直觉：一般人觉得「画精细点就行」。实际原因是——
识别靠的是**每条肢体的走向**；手臂贴着身体、两腿并在一起，就没有走向可循。

## 四、拿到图之后：一键自检

图放进「原始素材」后，在项目目录跑这条命令：

```powershell
cd D:\桌面文件\桌宠制作器
.\node_modules\electron\dist\electron.exe scripts\check-assets.mjs
```

它会逐个告诉你：

- **识别到几个关键点**（17 个满分）
- **认出了几个部位**（躯干 / 头 / 左右臂 / 左右腿，共 6 个）
- **合格 / 勉强 / 不合格**
- **不合格的具体原因 + 怎么改**（这句话可以直接拿去让豆包重画）

合格的会自动复制到 `素材\已通过自检\`。

> 前提：识别模型已下载（约 9MB）。如果提示「请先下载识别模型」，
> 打开制作器 →「身体」页 → 点「下载识别模型」。

## 五、自己肉眼快查（8 条全中才算好）

不想跑命令的话，对着看：

- [ ] 头顶到脚底都在画面里，四周有空白
- [ ] 双臂**明显离开身体**（能看到腋下的空隙）
- [ ] 双腿**明显分开**（能看到两腿之间的空隙）
- [ ] 手是**张开**的，没拿东西、没插兜、没抱胸
- [ ] 整个人**正面**朝镜头，身体没有侧转、没有倾斜
- [ ] 头身比在 **1:6 ~ 1:8** 之间（不是大头娃娃）
- [ ] 有**光影**（不是纯色块）
- [ ] 背景**干净**（纯色或简单渐变），没有地面阴影

**任何一条不满足，就拿回去让豆包改**，别急着放进制作器。

## 六、让豆包改图的话术（比重新生成省事）

如果某张不合格，把自检给的原因拼进这句话发给豆包：

```
这张图请按下面的要求重画，其他部分保持原样：
<把自检输出里「->」后面的那句话贴在这里>

例如：
把手臂和腿稍微张开，别贴着身体；分开得越清楚，动作越自然
```

**一次只改一件事**。比如先只让它「把手臂张开」，确认了再「把腿分开」。
一次改太多，容易把已经对的部分也改坏。

## 七、备选：其实不用 AI 也能做

如果你只是想要一只**自己捏的小人**，不需要 AI：

打开制作器 →「工坊」页 → 形体选「小人」→ 拖滑块
（配色 / 体型 / 耳朵 / 眼睛 / 嘴 / 头身比 / 腿长 / 手臂长度，左侧实时预览）。

那条路径的像素是**程序自己画的**：
- 不受识别率限制（不需要模型认出来）
- 能直接跳 8 种舞步
- 秒出，不用等 AI
