## 一、任务背景（让豆包理解为什么要这样画）

这些图会被用作**桌面宠物的角色素材**，后续要做两件事：

1. **自动识别身体部位** —— 用的是 MoveNet 模型（在真人照片上训练）
2. **驱动角色跳舞** —— 需要把手臂、腿当作独立部件来旋转

所以画面必须让模型能清楚认出**每条肢体的走向**。
我实测过（这些数字是真跑出来的）：

| 画法 | 识别到的关键点 | 结果 |
|---|---|---|
| 写实比例 + 有光影 + **四肢张开** | **17/17** | ✅ 合格 |
| 写实比例但**四肢并拢** | 8/17 | ❌ 被拒绝 |
| 扁平矢量小人（大头 Q 版） | 9/17 | ❌ 被拒绝 |

**两条铁律**：

1. **不要画大头 Q 版** —— 要接近真人比例（约 7 头身）
2. **四肢必须明显张开** —— 这条比「画得精细」影响大得多

> 上一批已经生成的 6 张里，有 5 张达到 17/17，说明这套要求是有效的。
> 本工单是在那批基础上**修正问题 + 扩充数量**。

## 二、硬性技术要求（每个角色都必须满足）

### 姿势

1. **正面朝向镜头**，身体站直，不侧身、不回头、不倾斜
2. **双臂向斜下方张开约 45 度** —— 腋下要能看到明显空隙，手臂不能贴着身体
3. **双腿分开** —— 两腿之间的距离要**接近髋宽**（这是本批的重点修正项）
4. **双手张开、掌心朝前**，不拿任何东西、不插兜、不抱胸、不背手
5. **脚要完整画出**，不能穿长裤遮住脚踝（否则识别不到踝关节）

### 身体与画风

6. **接近真人比例**，约 7 到 7.5 头身
7. **必须有清晰的人形躯干** —— 胸腔、腰、胯要有明确分界；
   **不要让肚子直接连着大腿**（上一批的猫和恐龙有这个毛病）
8. **柔和的赛璐璐上色**，有明确的光影和体积感（不要纯色色块）
9. **干净的纯浅灰背景**（#E8E8E8 左右），无道具、无场景、无地面阴影
10. **四周留白**：头顶到脚底完整入画，左右各留至少 10% 空白

### 反向要求（绝对不要出现）

```
chibi、超变形、大头小身子、夸张大眼睛、手臂交叉、手插口袋、手背在身后、
拿着任何物品、双腿并拢、双腿交叉、肢体互相遮挡、手脚被裁切、
侧视图、四分之三侧视图、背面、身体倾斜、坐姿、跳跃、
杂乱背景、场景元素、地面投影、动态模糊、低分辨率、
兽身人形（动物头直接接在动物身体上）
```

## 九、拿到图之后：一键自检（我这边跑）

图放进「原始素材」后，跑：

```powershell
cd D:\桌面文件\桌宠制作器
npm run check:assets
```

输出会逐个告诉你：**识别到几个关键点 / 认出几个部位 / 合格与否 / 具体怎么改**。
合格的会自动复制到 `素材\已通过自检\`。

> 前提：识别模型已下载（约 9MB）。
> 若提示「请先下载识别模型」，打开制作器 →「身体」页 → 点「下载识别模型」。

**不合格的怎么改**：把脚本输出里「->」后面那句话，原样拼进这个话术发给豆包：

```
这张图请按下面的要求重画，其他部分保持原样：
<把自检输出里「->」后面的那句话贴在这里>
```

一次只改一件事 —— 先只让它「把腿分开」，确认了再改别的。
一次改太多，容易把已经对的部分也改坏。

## 十、备选：其实不用 AI 也能做

如果你只是想要一只**自己捏的小人**，不需要 AI 生成：

打开制作器 →「工坊」页 → 形体选「小人」→ 拖滑块
（配色 / 体型 / 耳朵 / 眼睛 / 嘴 / 头身比 / 腿长 / 手臂长度，左侧实时预览）。

那条路径的像素是**程序自己画的**：
- 不受识别率限制（不需要模型认出来）
- 能直接跳 8 种舞步
- 秒出，不用等 AI
